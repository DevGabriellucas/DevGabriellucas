      ### 📊 Data Pipelines & ETL/ELT
      Construção de fluxos automatizados para coleta e tratamento de dados em larga escala, garantindo qualidade e eficiência.

      ### ⚡ Machine Learning Workflows
      Desenvolvimento e deploy de modelos preditivos simples e complexos para resolver problemas reais de negócio.

      ### 📈 Data Visualization & Dashboards
      Criação de visualizações estratégicas em Power BI e Python (Seaborn/Plotly) para storytelling com dados.

      ### 🧹 Data Cleaning & Wrangling
      Transformação de dados brutos em informações prontas para análise, tratando inconsistências e anomalias.

      Identificação de padrões, tendências e anomalias em grandes volumes de dados para descoberta de insights.

      ### 📱 Business Intelligence
      Tradução de problemas de negócio em soluções baseadas em evidências e dados.
